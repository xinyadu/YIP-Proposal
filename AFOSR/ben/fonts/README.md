# EB Garamond

These files are static instances of EB Garamond at weights 400 and 700, in regular and italic styles. They are bundled to make the white paper's typography reproducible without a system font installation.

Source: [Google Fonts / EB Garamond](https://github.com/google/fonts/tree/main/ofl/ebgaramond).

Upstream font objects used:

- Roman variable font: `52d34b86ec20977f222ce37e8158e6b3002c0a31`
- Italic variable font: `f9ad996001c8ee72fd43b4b8e67c8924b7f615b1`
