\head{Problem.} Autonomous agents retrieve knowledge, interpret images, use tools, and reason through multistep plans. An unnoticed error can invalidate an otherwise plausible trajectory: a resupply agent may read the quantity from the wrong row of a photographed inventory sheet and pass it to a planning tool. Outcome rewards reveal only that the plan failed; generic self-critique may miss the original visual error. Reliable agents need to connect their decisions to verifiable evidence, identify the source of errors, and learn to correct them.
\par\head{Central hypothesis.} We hypothesize that combining neuro-symbolic evidence representations with fine-grained error diagnosis will help agents correct failures and improve their reasoning policies. Explicit links between observations, inferences, and actions enable verifiable feedback about what went wrong; training on this feedback should improve recovery and generalization beyond outcome-only or scalar process rewards.
\par\head{Research plan.}
\begin{itemize}
\item \textbf{Develop neuro-symbolic representations of evidence-grounded agent reasoning.} Connect neural interpretation of text, images, and tool observations to structured representations of entities, events, preconditions, and inferential dependencies. Explicitly track alternative interpretations and provenance so symbolic checks can distinguish unsupported observations from invalid deductions or actions. Investigate when evidence and inference constraints can expose inconsistencies despite uncertain perception, and how to maintain valid conclusions as observations or external states change.
\item \textbf{Learn fine-grained self-assessment of agent reasoning.} Develop a verifier that identifies and explains errors in multistep agent trajectories, distinguishing failures in knowledge retrieval, visual understanding, logical reasoning, and tool use. Construct training data by introducing controlled errors into successful trajectories and collecting naturally occurring failures, with supervision identifying the erroneous step, error type, and supporting evidence. Train the verifier to produce structured diagnostic feedback, including the location and cause of an error, rather than a single correctness score. Improve robustness through training on diverse tasks and environments, and calibrate the verifier's confidence using independently validated trajectories.
\item \textbf{Turn diagnosis into agent self-improvement.} Condition the next action on the diagnosed failure: re-examine an image region, retrieve a missing fact, repair a tool argument, backtrack, or abstain. Use error-aware process feedback and successful corrective trajectories to train improved policies, while checking final outcomes independently to detect reward exploitation. Compare type-conditioned correction training against scalar process rewards, and test whether reducing one error type causes new failures elsewhere. Measure improvement across training rounds as well as immediate repair success, including cases where repeated self-correction wastes resources.
\end{itemize}
\head{Evaluation and expected outcomes.} Evaluate on \href{https://proceedings.neurips.cc/paper_files/paper/2024/hash/e560a0b22e4432003d0dba63ff8dc457-Abstract-Datasets_and_Benchmarks_Track.html}{\textcolor{blue}{MEQA}}, \href{https://arxiv.org/abs/2311.12983}{\textcolor{blue}{GAIA}}, and \href{https://arxiv.org/abs/2406.12045}{\textcolor{blue}{$\tau$-bench}}, supplemented by controlled trajectories with verified evidence links, error types, and outcomes. Measure evidence-grounding fidelity, diagnostic accuracy and calibration, successful correction, and task improvement after training. Compare with outcome-only RL, scalar process rewards, and LLM self-critique at matched computation and tool cost.
\par\head{Naval relevance.} A Naval logistics support agent may combine a photographed inventory list, written guidance, and a resupply-planning tool. The proposed system would link each planning decision to its supporting evidence, flag a misread inventory entry, and use the diagnosis to correct the tool input and improve subsequent decisions. This addresses the program's interests in uncertain reasoning and self-assessment, visual understanding, and the integration of knowledge, learning, and planning.
